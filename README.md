# Raíz Verde · Grow Shop

Web estática de un grow shop: abre `index.html` en el navegador.

- `index.html` – estructura y contenido
- `styles.css` – estilos (responsive)
- `script.js` – catálogo, filtros, carrito (guardado en el navegador), aviso +18 y newsletter

Para editar productos, modifica el array `PRODUCTS` en `script.js`.
